# Travel Unbounded

Travel Unbounded is a travel website built with Next.js that allows users to explore travel destinations and submit travel enquiries through the website.

## Features

- Travel destination information
- Responsive design
- Travel enquiry/contact form
- MongoDB database integration
- REST API for enquiries
- Next.js App Router
- Modern and responsive UI

## Tech Stack

- Next.js
- React
- JavaScript
- MongoDB
- Mongoose
- CSS
- Vercel
